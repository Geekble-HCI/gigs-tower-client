# Game Part - ESP32 센서 코드

삼양 팝업 게임의 물리적 센서 처리를 담당하는 ESP32 펌웨어들입니다.

## 💡 간단 요약

- **GEEKBLE_SEESAW_Arduino**: 시소 게임 - 가속도 센서로 기울기 감지 (기존 Rpi Pico 코드를 Arduino Nano용으로 변경)
- **GEEKBLE_GOAL**: 농구 게임 - 초음파 센서로 골인 감지
- **GEEKBLE_BALL**: 볼풀 게임 - 8개 초음파 센서로 볼 감지

## 📁 구성

```
game-part/
├── _LEGACY_/    # 기존코드
├── GEEKBLE_SEESAW_Arduino/ # 시소 게임 (Arduino Nano, 게임 타입 5)
├── GEEKBLE_GOAL/      # 농구 게임 (게임 타입 6)
└── GEEKBLE_BALL/      # 볼풀 게임 (게임 타입 4)
```

## 🎯 펌웨어 설명

### GEEKBLE_SEESAW (시소 게임)

**용도**: 바이오데이터 에어시소 게임의 기울기 변화 감지

**센서**: 가속도계 (X/Y/Z 축)

- 시리얼 통신으로 센서 데이터 송신 (115200 baud)
- 주기적으로 시리얼 버퍼 비우기(타워쪽에서 주기적으로 보내는 시리얼 버퍼를 비우지 못하면 병목현상이 생겨 코드를 추가함)
- 처음 3초간 데이터를 바탕으로 기울기 원점 설정
- 시소 기울기 변화 감지 시 점수 전송
- #define에 정의된 상수를 통해 오차 범위값 수정가능
- 센서 감지시 LED 상태변화
- 코드 업로드시 Rx핀 스위치 off를 하여 Rx핀 로드를 없앤 후 업로드 해야함

**출력**:

- 기울기 방향 변경 시 → 시리얼로 `'1'` 전송
- 데드타임: 20ms (연속 감지 방지)

**핀 설정**:

```
Serial1 RX: 아두이노 RX핀
```

### GEEKBLE_GOAL (농구 게임)

**용도**: 슛잇! 무빙 골대 게임의 골인 감지

**센서**: 초음파 센서 1개 (HC-SR04)

- 주기적으로 시리얼 버퍼 비우기(타워쪽에서 주기적으로 보내는 시리얼 버퍼를 비우지 못하면 병목현상이 생겨 코드를 추가함)
- 골대 근처 물체 감지
- 목표 거리: 2.8m 이내

**출력**:

- 골인 감지 시 → 시리얼로 `"10"` 전송
- 데드타임: 2초 (중복 감지 방지)

**핀 설정**:

```
TRIG: 6번 핀
ECHO: 3번 핀
```

### GEEKBLE_BALL (볼풀 게임)

**용도**: 볼볼볼 영양소 게임의 볼 감지

**센서**: 초음파 센서 8개 (HC-SR04)

- 주기적으로 시리얼 버퍼 비우기(타워쪽에서 주기적으로 보내는 시리얼 버퍼를 비우지 못하면 병목현상이 생겨 코드를 추가함)
- 8개 구역에서 동시 볼 감지
- 목표 거리: 2.65m 이내

**출력**:

- 각 센서별 볼 감지 시 → 시리얼로 `'2'` 전송
- 데드타임: 150ms (센서별 독립)

**핀 설정**:

```
TRIG 핀: 17,16,10,11,21,20,19,18
ECHO 핀: 6,7,8,9,2,3,4,5
```

## ⚙️ 설치 및 사용법

### 1. Arduino IDE 설정

```
보드: ESP32 Dev Module
업로드 속도: 115200
시리얼 모니터: 115200 baud
```

### 2. 하드웨어 연결

#### 시소 게임 (SEESAW)

- 가속도 센서를 Serial1에 연결
- TX(12), RX(13) 핀 사용

#### 농구 게임 (GOAL)

- HC-SR04 초음파 센서 1개
- TRIG(6) → ESP32 6번 핀
- ECHO(3) → ESP32 3번 핀

#### 볼풀 게임 (BALL)

- HC-SR04 초음파 센서 8개
- TRIG 핀: 17,16,10,11,21,20,19,18
- ECHO 핀: 6,7,8,9,2,3,4,5

### 3. 게임 클라이언트 연동

각 ESP32는 게임 클라이언트와 시리얼 통신으로 연결됩니다:

```python
# gigs-tower/Module/serial_handler.py에서 처리
if data.strip() == '1':    # 시소 점수
    self.score_manager.add_score(1)
elif data.strip() == '2':  # 볼풀 점수
    self.score_manager.add_score(2)
elif data.strip() == '10': # 농구 점수
    self.score_manager.add_score(10)
```

## 🔧 설정 값

### 감지 거리 설정

- **농구 (GOAL)**: `d_goal = 2800` (2.8m)
- **볼풀 (BALL)**: `d_goal = 2650` (2.65m)

### 데드타임 설정

- **농구 (GOAL)**: `dead_time = 2000` (0.5초)
- **볼풀 (BALL)**: `dead_time = 150` (150ms)

### 센서 주기

- **시소 (SEESAW)**: 기울기값 시리얼 읽기
- **농구 (GOAL)**: 25ms 주기로 초음파 측정
- **볼풀 (BALL)**: 10ms 주기로 초음파 측정

## 🚨 주의사항

1. 파이썬 코드에서 주기적으로 시리얼 값을 보내는데, 이 시리얼 버퍼를 주기적으로 비워야함
2. 시소코드 업로드시 RX스위치를 전환해 코드 업로드시 문제 없도록 해야함.
